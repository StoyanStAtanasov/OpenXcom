# OpenXcom Browser TypeScript Port

This directory is a faithful TypeScript/browser translation scaffold. It keeps the original C++ class names, method names, and source grouping where practical:

- `web/src/main.ts` mirrors `src/main.cpp`.
- `web/src/Engine/*` mirrors the translated engine slice: `Game`, `State`, `Action`, `Screen`, `Surface`, `SurfaceSet`, `InteractiveSurface`, `Timer`, `Font`, `Unicode`, `Language`, `Options`, `RNG`, `Logger`.
- `web/src/Interface/*` mirrors the first UI primitives: `Text`, `TextList`, `TextEdit`, `TextButton`, `BattlescapeButton`, `Window`, `Frame`, `Bar`, `ComboBox`, `Slider`, `Cursor`, `FpsCounter`.
- `web/src/Interface/*` also includes `ToggleTextButton` for option-style push/toggle controls.
- `web/src/Menu/*` mirrors the loading and menu flow: `StartState`, `GoToMainMenuState`, `MainMenuState`, `NewGameState`, `NewBattleState`, `ErrorMessageState`, `CutsceneState`, and `StatisticsState`.
- `web/src/Geoscape/*` starts the geoscape slice with `GeoscapeState`, `BuildNewBaseState`, `BaseNameState`, `ConfirmNewBaseState`, `Globe`, and the first worker-built popup states including `InterceptState`, `SelectDestinationState`, `MultipleTargetsState`, `UfoDetectedState`, `MissionDetectedState`, `GeoscapeCraftState`, and related craft/target popups.

The build is dependency-free on Node 24+:

```powershell
cd web
npm run build
npm run serve
```

Then open `http://127.0.0.1:4173/web/index.html`.

For compact resume/subagent context:

```powershell
cd web
npm run context
npm run context -- --slice "Geoscape popup batches"
npm run context:readonly
npm run context:worker
npm run agents
npm run agents:prompt -- --role readonly --task "audit assigned source" --scope "src/Foo.cpp; web/src/Foo.ts"
```

This refreshes translation status and writes `web/CONTEXT_PACKET.md` plus `web/context-packet.json`. Use `--slice` to target a named slice and `context:readonly` / `context:worker` for shorter sidecar or worker prompts instead of loading this whole porting narrative when a slice only needs the active queue, source files, target files, boundaries, and verification commands.
Use `npm run agents:start` and `npm run agents:close` around spawned subagents to keep a local scope ledger and catch overlapping assignments before workers touch the same files.

`npm run build` also writes `web/dist/resource-manifest.json` so the browser runtime can avoid 404 probes for optional original data files. It currently detects UFO/X-COM data from `XCOM/` or `bin/UFO/`, and TFTD data from `TFD/`, `TFTD/`, or `bin/TFTD/`, including GEODATA minimap data, GEOGRAPH, UFOGRAPH scanner/medikit/unit-info/minimap resources, SOUND CAT/MID file lists, TERRAIN, MAPS, ROUTES, LOFTEMPS, FLOOROB, and common soldier-name pools.
